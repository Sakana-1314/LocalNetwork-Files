# 在线 Demo

不用安装，直接在下方试用 MList 界面。这是一个**真实的前端**，数据来自 Apifox 云端 Mock。

<ClientOnly>
  <DemoFrame src="/app/" title="MList 在线 Demo" />
</ClientOnly>

## 怎么用

1. 用任意用户名与密码登录（Mock 不校验凭据）。
2. 左侧进入「文件」浏览目录，可点击进入子目录、切换列表 / 网格视图、使用搜索。
3. 「挂载与服务」「用户管理」「系统管理」等页面都可以打开。

## 关于数据

- 所有数据都是 **Mock 生成的假数据**，写操作（上传、新建、删除等）不会真正落盘。
- 媒体预览、转码与下载不可用：Mock 对二进制接口也只返回 JSON。
  这是演示环境的限制，不是功能缺失。
