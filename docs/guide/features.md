# 功能

## 文件管理

浏览（列表 / 网格两种视图）、新建文件夹、重命名、移动、复制、删除、下载。
支持拖放上传与多文件上传队列，上传过程中显示速度与进度。

## 在线预览

- **图片**：常见格式直接显示。
- **视频**：浏览器可直接播放的格式直接串流原文件（支持 Range 请求）；
  无法直接播放的实时转码，见下节。支持多音轨切换与内嵌 / 外挂字幕。
- **音频**：直接播放，必要时实时转为 MP3 串流。
- **PDF**：内嵌阅读。
- **文本 / 代码**：在线查看并可直接编辑保存。

## 实时转码串流

播放前先用 ffprobe 探测；浏览器可直接播放的格式直接串流原文件（支持 Range），否则创建转码会话。

会话立即返回**完整的 VOD 播放列表**，因此可拖动到任意位置；分片**按需生成**——请求的分片不在磁盘、
也不在 ffmpeg 即将产出的范围时，会从该时间点重新开始转码。关键帧强制对齐分片边界，不同次运行的分片
可无缝拼接。已生成的分片按文件内容 / 清晰度 / 音轨复用，并按[缓存](/guide/config#缓存)的保留时长与
容量上限清理，正在播放的会话不会被清理。

编码器在 `config.yaml` 的 `transcode.encoder` 中选择：`libx264`（软件）、
`h264_videotoolbox`（macOS）、`h264_nvenc`（NVIDIA）、`h264_qsv`（Intel）、`h264_vaapi`（Linux VA-API）；
硬件编码失败时自动回退到 libx264。

可选画质：原画 / 1080p / 720p / 480p。

## 预览图与缓存治理

自动生成多尺寸缩略图（128 / 256 / 512 / 1024）。预览图与转码分片分别设置保留时长与容量上限，
超出后按最近最少使用（LRU）淘汰。

缓存以**文件内容**为标识（大小 + 首尾各 64 KiB 的哈希），因此移动、重命名或更换挂载目录都不会让
预览失效；内容相同的文件共用同一份缓存。

## 用户与权限

管理员按目录授权，为每个用户设置**只读**或**可读写**。REST、WebDAV、S3 共用同一套权限检查，
只读授权对所有协议生效。

用户密码除 bcrypt 哈希外，还会用 `data_dir` 下的 `secret.key` 加密保存一份可逆副本，供管理员在
用户管理中查看并转述给用户；登录校验始终只使用 bcrypt 哈希。

## 访问令牌

带 `read` / `write` 范围与有效期的 API 令牌（`ml_` 前缀），明文加密存储，可随时在设置中再次查看。
令牌只保存哈希（S3 Secret 用服务器密钥加密保存），可随时吊销。

## 协议与挂载

WebDAV（`/dav`）、S3 兼容接口（每个授权桶一个 bucket）、SMB（托管 Samba）。
详见[挂载与服务](/guide/mount)。

## 模糊搜索

常驻内存的文件名索引，fzf 风格子序列匹配打分，只返回当前用户有权访问的文件。
索引可通过文件系统事件增量更新，也可定时全量重建。

## 界面

深色模式，桌面与移动端自适应（窄屏为抽屉式导航）。
